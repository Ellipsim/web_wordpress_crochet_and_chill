# Desarrollo de sitio web profesional con WordPress

> Proyecto real de desarrollo web para un cliente: desde la identificación de sus necesidades y la planificación hasta el diseño, la configuración técnica y la publicación del sitio web.

## Descripción del proyecto

Este proyecto consistió en el desarrollo y la puesta en marcha de un sitio web para un cliente que disponía de una negocio de crochet. Su objetivo era el de establecer una presencia digital y ofrecer a sus usuarios una experiencia de navegación clara, accesible y adaptada a sus necesidades.

Me encargué de gestionar el proceso de desarrollo de principio a fin, incluyendo la búsqueda y captación del cliente, la definición de los requisitos, la planificación del proyecto, la configuración de WordPress, la adaptación del diseño y la implementación de las funcionalidades necesarias para su publicación.

El proyecto me permitió trabajar en un escenario real, combinando competencias técnicas, organización, comunicación con el cliente y resolución de problemas.

## Objetivos

- Comprender las necesidades del cliente y transformarlas en una solución web.
- Diseñar una estructura de páginas clara y fácil de navegar.
- Configurar WordPress como sistema de gestión de contenidos.
- Seleccionar y adaptar una plantilla adecuada al proyecto.
- Implementar las funcionalidades necesarias mediante plugins.
- Comprobar la presentación del sitio en diferentes dispositivos.
- Publicar el sitio web y comprobar su funcionamiento.
- Entregar una solución que el cliente pueda utilizar y mantener.

## Mi papel en el proyecto

Participé en las distintas fases del ciclo de vida del proyecto:

### 1. Captación y contacto con el cliente

- Búsqueda y contacto con un cliente potencial.
- Identificación de sus necesidades y objetivos.
- Definición del alcance del proyecto y de los requisitos principales.
- Comunicación y seguimiento durante el desarrollo.

### 2. Planificación

- Organización de las tareas necesarias para desarrollar el sitio.
- Definición de la estructura de páginas y contenidos.
- Selección de las herramientas y tecnologías adecuadas.
- Planificación de la implementación y puesta en marcha.

### 3. Diseño y desarrollo web

- Instalación y configuración de WordPress.
- Selección y configuración de una plantilla acorde con las necesidades del proyecto.
- Adaptación del diseño, la estructura y los contenidos.
- Creación y organización de las páginas del sitio.
- Configuración de menús, navegación y elementos visuales.
- Instalación y configuración de plugins para ampliar las funcionalidades.

### 4. Pruebas y revisión

- Revisión de la estructura y navegación.
- Comprobación del funcionamiento de las páginas y funcionalidades.
- Revisión de la presentación en escritorio y dispositivos móviles.
- Detección y corrección de problemas durante el proceso.
- Verificación final antes de la publicación.

### 5. Publicación y entrega

- Preparación del entorno de alojamiento.
- Publicación del sitio web en el servidor.
- Comprobación del funcionamiento después de la publicación.
- Revisión final del resultado y preparación para su utilización por parte del cliente.

## Tecnologías y herramientas

| Tecnología | Uso |
|---|---|
| WordPress | Sistema de gestión de contenidos (CMS). |
| PHP | Tecnología del entorno WordPress; indicar desarrollo propio únicamente si se escribió o modificó código PHP. |
| HTML y CSS | Estructura y presentación del sitio, cuando corresponda a las personalizaciones realizadas. |
| JavaScript | Interactividad adicional, si se implementó. |
| Plugins de WordPress | Incorporación y configuración de funcionalidades. |
| Plantilla de WordPress | Base visual y estructural del sitio. |
| Alojamiento web y dominio | Publicación y disponibilidad del sitio en Internet. |
| Git y GitHub | Documentación y presentación del proyecto en el portfolio, si se utilizan. |

*Las tecnologías y herramientas se incluyen según su participación real en el proyecto. El uso de WordPress no implica necesariamente haber desarrollado código propio con todas las tecnologías mencionadas.*

## Resultado

El resultado fue un sitio web publicado para un cliente real, desarrollado a partir de sus necesidades y preparado para su uso.

El proyecto me permitió adquirir experiencia práctica en:

- Gestión integral de un proyecto web.
- Comunicación y coordinación con un cliente.
- Configuración y administración de WordPress.
- Adaptación de plantillas y funcionalidades.
- Organización de contenidos y estructura web.
- Pruebas, revisión y publicación de sitios web.
- Resolución de incidencias durante el desarrollo.


## Retos y aprendizajes

Uno de los principales aprendizajes fue gestionar un proyecto real más allá de la parte técnica. El proceso exigió comprender las necesidades de otra persona, organizar las tareas, seleccionar las herramientas adecuadas y comprobar que el resultado respondiera a los objetivos definidos.

También adquirí experiencia en la configuración de WordPress, la adaptación de una plantilla, la incorporación de plugins y la puesta en marcha de un sitio web en un entorno de alojamiento real.
